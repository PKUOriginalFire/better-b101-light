# Better B101 Light · B101 灯光控制台

给 **grandMA2 onPC** 套一层「一看就会」的浏览器操作界面：台灯、灯组、颜色、亮度、时长、延时、快捷效果、
演出 cue 列表，全在网页里点。后台把这些操作翻译成 MA2 命令行，通过 **Telnet（30000 端口）** 发给控台。

**不改控台里的任何灯具编号、灯组和预设** —— 只在旁边下命令。

![界面截图](docs/screenshot-console.png)

![MA3D 预览](docs/screenshot-3d.png)

---

## 这个界面解决什么问题

MA2 的命令行很强，但演出时手忙脚乱地敲 `Fixture 21 Thru 33 At 60 Fade 3` 不现实。
这个工具把常用的东西全做成按钮和推子，同时保留原始命令行输入框 —— 想敲命令随时能敲。

- 给 **46 台灯**（B101 配置：6 左耳光 + 8 面光 + 6 右耳光 + 13 顶光前 + 13 顶光后）做了一张**舞台平面图**，点灯就能选
- 颜色同时支持 **RGB（0–100 / 0–255 / HEX 三种进制）**、**HSV 色轮**、**色温**（面光是 Vario-Temp 白灯）
- 所有数值都能**直接键盘输入**，不用拖着滑块凑数
- 8 个快捷效果，实时在控台里跑，可设速度与持续时长
- 演出用的 **cue 列表可以直接读写控台上的 sequence**，挂在推杆 executor 上，跟着 `.show.gz` 走

## 快速开始

**第 1 步：让控台允许远程命令**（只需一次，做完记得存 show）

在 MA2 命令行里执行：

```
Assign "Global" /Telnet="Login Enabled"
```

然后 `SaveShow` 存一下 —— 这个设置写在 show 文件里，不存的话重启就丢了。

**第 2 步：装 Node.js**

去 <https://nodejs.org/> 下载 LTS 版，双击安装，一路「下一步」。

**第 3 步：启动**

双击 `启动控制台.bat`（或在这个目录里执行 `npm start`）。
浏览器会自动打开 <http://127.0.0.1:8801>，顶栏显示 **控台已连接** 就通了。

关掉那个黑色命令行窗口 = 停止服务。

> 想让平板/手机也能操作：在 `启动控制台.bat` 里 `node server.js` 上面加一行 `set HOST=0.0.0.0`，
> 然后用平板访问 `http://电脑IP:8801`（防火墙记得放行 8801）。

## 配置

全部在 `config.json`：

| 键 | 说明 |
|---|---|
| `ma2.host` / `ma2.port` | 控台地址与 Telnet 端口，默认 `127.0.0.1:30000` |
| `ma2.user` / `ma2.password` | 控台登录账号，默认 `administrator` / `admin`（MA2 出厂默认） |
| `server.port` | 网页端口，默认 `8801` |
| `cue.executor` | cue 列表挂在哪个推杆上，默认 `1.1` |
| `fixtures` / `groups` / `palette` | 灯具、灯组、颜色预设，由界面上的 **同步** 按钮自动生成 |

**换到别的场地/别的配接**：点界面左上「同步」，程序会从控台重新读取灯具（含 3D 坐标）、灯组和颜色预设，
覆盖写回 `config.json`。不需要手改。

## 界面说明

详细用法见 **[docs/使用说明.md](docs/使用说明.md)**（安装、每个区块怎么用、cue 列表、常见问题）。

几个要点：

- **舞台平面**：方框 = 彩光帕灯，圆点 = 色温灯；点选、`Shift` 连选、`Ctrl` 加减选
- **时长 / 延时**：`时长 3` = 3 秒内淡到新亮度；`延时 1` = 按下后先等 1 秒再开始变
- **效果**：呼吸、心跳、频闪、追逐、波浪、随机、彩虹、轮转；每块右下角 `…` 有实现说明
- **演出 Cue**：读写控台上推杆 `1.1` 的 sequence，支持 `Go / Time / Follow` 三种触发
- **临时快照**：只存在浏览器本地，8 格 + 自动存档，不写控台

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 顶栏显示「控台未连接」 | 控台没开，或 Telnet 没启用（见快速开始第 1 步） |
| 连上了但命令没反应 | 检查 `config.json` 里的账号密码；MA2 的 telnet 只认 `administrator` 这类有权限的账号 |
| 启动就报 `EADDRINUSE` | 8801 端口被占用，改 `server.port` 或关掉旧的服务窗口 |
| 灯的颜色不对 | 面光是 Vario-Temp 白灯，没有 RGB；这是灯具本身决定的，界面会自动只给色温 |
| 提示 `Remote commandline disabled` | Telnet 没开，或者开了没存 show |
| 第二个窗口一直连不上 | MA2 的 telnet 同一个账号只允许一个会话；先关掉已经在跑的那个服务窗口 |
| 演出时网页很卡 | 关掉浏览器里其它标签页；cue 列表超过几百条时，切换 cue 页会重绘较慢 |
