# B101 灯光控制台

给 grandMA2 onPC 套一层「一看就会」的操作界面。台灯、灯组、颜色（RGB + HSV + 色温）、
亮度、时长、延时、快捷效果、场景记忆，全部在浏览器里点，后台翻译成 MA2 命令经 Telnet 发给控台。

不修改控台里的任何灯具编号、灯组和预设 —— 只是在旁边下命令。

---

## 一、启动

1. 先打开 **grandMA2 onPC**，载入演出用的 show（当前是 `tutorial1`，含完整 B101 配接）。
2. 双击 **`启动控制台.bat`**。
3. 浏览器自动打开 <http://127.0.0.1:8801>。
4. 右上角显示 **控台已连接** 就说明通了。

关闭那个黑色命令行窗口 = 停止服务。

> 想让平板/手机也能操作：在 `启动控制台.bat` 里 `server.js` 前面加一行 `set HOST=0.0.0.0`，
> 然后用平板访问 `http://电脑IP:8801`。

### 控台必须开着 Telnet

MA2 默认关闭远程命令。控台里执行：

```
Assign "Global" /Telnet="Login Enabled"
```

这一步会写进 show 文件，**重启控台前记得 Save**，否则会丢。
（`Assign "Global" /Remotes="Login Enabled"` 是网页远程，本工具不需要。）

## 二、界面怎么用

### 左：舞台平面
- 46 台灯按控台里的 3D 坐标画成俯视图：**方框 = 彩光帕灯（38 台）**，**圆点 = 色温灯（8 台）**。
- 点一台 = 只选它；**Shift + 点** = 选一段；**Ctrl + 点** = 加选/减选。
- 选中的灯有琥珀色描边，点亮的灯会发光。
- 下面一排是控台里原有的 11 个灯组：全部 / 顶光 / 顶光前 / 顶光后 / 面光 / 面光左 / 面光右 / 耳光 / 耳光左 / 耳光右。
- **同步** 按钮：从控台重新读取灯具、灯组、颜色预设（改了配接之后点一下）。

### 中：亮度 / 时间 / 效果
- **亮度**：横向推子（拖、滚轮微调），下面一排 关 / 25 / 50 / 75 / 满；右上角数字框可以**直接键入** 0–100。
- **时长（Fade）**：0–120 秒，滑块、快捷档（1s/2s/3s/5s/10s）或者**在数字框里直接输入**（支持 2.5 这样的小数）。回车生效，下一次改亮度就用这个时间淡过去。
- **延时（Delay）**：按下去后**先等多久**才开始变（等着的时候灯保持原样），同样可以直接输入。
  例：延时 1s + 时长 3s = 按下后 1 秒开始动，再用 3 秒淡到目标。这两个值都会夹进下发命令里
  （`At 60 Fade 3 Delay 1`），控台 cue 里能看到对应的 `<Fade>` / `<Delay>`。
- **效果**：呼吸、心跳、频闪、追逐、波浪、随机、彩虹、轮转。选好灯再点效果；
  **持续** 设成 3/5/10/30 秒（或直接输入，0 = 不限）就到点自动停，并把灯恢复成开始效果前的亮度与颜色；
  **速度** 1–20 可调（也能直接输入）；再点一次或按 **停止** 是立刻停（灯停在最后一帧）。
  每块右下角的 **…** 会弹出这个效果的实现说明（周期几秒、亮度范围、每帧发什么命令）。

> **速度** = 每秒刷新几次（1–20 次/秒），对呼吸/心跳同时决定周期长短，对频闪就是每秒闪几下，
> 对追逐是每秒挪几盏；彩虹/轮转的转色速度是写死的（4 秒 / 9 秒一圈），速度只影响变化是否细腻。
> **停止** 只是停掉循环，不会把灯复位——灯停在最后一帧的亮度，要归零得手动点亮度 0 或 Clear。
> 效果运行期间，上面的亮度推子不起作用（亮度由效果曲线自己给）。

> 所有数字框都可以点一下直接打字，回车提交、Esc 取消。带 `%` / `s` / `×` 单位的就是可输入项。

### 右：颜色
- **色轮**：外圈拖动 = 色相，离中心越近越淡（就是 MA2 Color 窗口的用法）。
- **H / S / V** 三条滑块 —— 对应色相、饱和、明度，右侧数字框可直接输入（H 0–360，S/V 0–100）。
- **R / G / B / W** 四条滑块，同样的值可以按三种进制看和输入（右上角切换）：
  - `0–100`：控台内部值（100 = 满），平时用这个；
  - `0–255`：跟 PS / 灯光本一个口径；
  - `HEX`：直接打 `FF`、`00` 这种两位十六进制。
  数字框里打的数会按当前进制自动换算，滑块和色轮跟着联动。
- **色温** 滑块只作用在那 8 台色温灯上；选彩色时它会自动跟着色相走（暖色偏暖白、冷色偏冷白），
  手动拖过 / 输入过之后就固定为你设的值，再点色轮或色板会恢复自动跟随。
- **色板**：控台里已有的 7 个颜色预设 + 剧目常用的橙 / 金 / 粉 / 暖白 / 冷白。
- 右上角 `#FF9A33` 是当前颜色的十六进制，**可以直接改了回车**：粘贴 `#FA6B00`（支持 `#F60` 简写），
  一键落到灯上，跟灯光本上的色号对色最快。

### 底：演出 Cue / 临时快照 / 指令
底栏有两个标签页：**演出 Cue**（默认，存控台，跟着 `.show.gz` 走）和 **临时快照**（只存这台电脑的浏览器，8 格）。
标签上有一行小字写着这一点，鼠标停上去也有完整说明。

#### 演出 Cue —— 真正的 cue list，写进控台
- 这条列表会**在控台上建一条真正的 sequence**（executor `1.1`（推杆）），触发方式用的是控台原生的
  Go / Time / Follow，所以控台自己的推子、Go 键、时间码都照常能用。
- `#` 序号 · `名称`（可改，中文没问题）· `触发` · `时间` · `时长` · `延时`，每行直接改，
  改完自动重新写进控台（右侧显示「正在写…」，一次约 1–2 秒）。
- **记录当前**：把现在选中的灯 / 亮度 / 颜色 + 当前的时长、延时，追加成一条新 cue。
- **GO**：从头开始播 / 播下一条。**←**：回上一条。**停**：停掉这条 sequence（灯保持当前状态）。
- 双击序号 = 跳到那一条。
- 右上角 `▶ Cue 3 副歌 · 下一条 4.2s` 是本地跟出来的播放状态：控台的 Time / Follow 到点自己会走，
  这里同步显示还有多久到下一 cue。
- **同步**：把整个列表重新写一遍进控台（改了 `cues.json`、或者控台上那条 sequence 被手动动过之后用）。

三种触发方式（跟控台里 Cue 的 Trig 列一一对应）：

| 触发 | 含义 | 「时间」填什么 |
| --- | --- | --- |
| **Go** | 等你按 GO 才走 | 不填（填了反而会被改成 Time） |
| **Time** | 这一条被触发之后，过 N 秒自动走 | 从**本条被触发**起算的秒数 |
| **Follow** | 上一条的 **时长 + 延时** 全部走完，再自动走 | 走完之后再额外等几秒（一般 0） |

所以「上一条多久，下一条就多久跟」用 Follow 就行，不用自己算——控台会自己等上一条 fade+delay 走完。
想「上一条 GO 下去 8 秒后走」，用 Time 填 8。

> 注意：cue 的数值以网页里的列表为准。如果你在控台上手动 `Store`/`Delete` 了 cue，
> 网页这边不会知道，点一次 **同步** 就对齐了。

#### 读取控台 —— 换 show 之后自动对齐
- **读取控台** 按钮（底栏右侧）：把**控台当前载入的那个 show** 里挂着 sequence 的 executor 上的 cue
  全部读回来，名称、触发方式、Trig Time、时长、延时、每台灯的亮度和颜色都对上，列表直接换成它的内容。
- **自动**：后台每 12 秒对比一次「哪个 executor 挂着哪条 sequence + 这条 sequence 有几条 cue」。
  只要你在大屏上 `LoadShow` 换了文件，十几秒内列表会自己换成新 show 的内容，
  右下角小字会从 `本地列表` 变成 `控台 1.1 · Seq 2 · testbyds · 10 条`，并弹一句「控台的 show 变了，已重新对齐」。
- 读回来的是**绝对值**：控台按跟踪存值，某条 cue 没写到的灯会沿用上一条，读的时候已经补齐，
  所以左侧舞台平面的实时预览和完整预览都能照常走。
- 如果那个 show 里根本没有挂 sequence 的 executor（比如 `b101_v2.3.1`、`cp1-1` 这两个模板 show
  只有灯位/灯组/颜色预设），会提示「控台当前 show 里没有挂 cue 的 executor（列表还是原来那批，没对齐）」，
  **不会**把本地列表清空——你辛苦排的 cue 不会因为切了个空 show 就没了。
- 读的时候控台那边是静音的（`List` / `Export` 的输出不进日志面板），读一次大约 1 秒。

#### 临时快照（浏览器本地）
- **保存** 按钮（或 `Ctrl+S`）：弹出面板，选 8 个场景槽之一或「自动存档」，可以起名；
  存的是**当前选中的灯 + 亮度 + 颜色 + 时长**，再点那个槽就原样还原并下发到控台。
- **场景槽**：点一下调用，**长按 0.6 秒**直接打开保存面板并预选这一格。数据存在浏览器本地，不动控台。
- **自动保存**：右侧下拉选 关闭 / 1 / 3 / 5 / 10 分钟。开着的时候，每隔这么久把当前状态写进
  「自动存档」这一格，排练时不怕手滑调乱。下面那行 `自动存档 · 01:44 · 46 台 · 100%` 点一下就还原。

#### 指令
- **控台指令**：直接敲 MA2 命令，回车发送。例如
  `Fixture 21 Thru 33 At 70 Fade 2`
- **日志**：看实际发出去的每一条命令和控台的报错。

键盘：`Esc` 取消选择（弹窗里 = 关闭弹窗），`Ctrl+A` 全选，`Ctrl+S` 保存快照。

## 三、排一份灯光本怎么走

1. 选灯组（比如「顶光前」）→ 调亮度 → 调颜色 → 设时长。
2. 满意了，点 **记录当前**，它就变成 cue 列表里的一条；名字可以之后改。
   想先存着慢慢排，也可以用 **快照** 存到场景槽。
3. 下一段换一组灯、换个颜色，再记一条。两条之间要自动接，就把下一条的触发改成 Time/Follow。
4. 排练时按 **GO** 一条条走；需要临场改顺序，直接拖行里的 ↑↓ 或者双击序号跳过去。
5. 排完了，点右上角 **存演出** → **保存并归档**，见下一节。

### 存演出 —— 怎么弄到真正控灯那台电脑

这台机器只是模拟，灯是控台算出来的。真正上舞台时，把整个 show 文件搬过去就行：

1. 点 **存演出**，文件名填一个你认得的（默认 `b101_live`），点 **保存并归档**，等它变回按钮（约 3–5 秒）。
   - 控台自己执行 `SaveShow "b101_live" /noconfirm`，写出 `...\gma2_V_3.9.60\shows\b101_live.show.gz`；
   - 同时往本机 `b101-light\exports\` 复制一份 `b101_live_20261106-1232.show.gz`（带时间戳，每次存都不会覆盖旧的）。
2. 点弹窗里的 **归档文件夹** 直接打开 `exports`；U 盘 / 网盘拷走最新那份。
3. 到演出电脑上：打开 grandMA2 onPC → **Backup → Load Show** → 选这个 `.show.gz`。
   灯具编号、灯组、颜色预设、cue 列表、executor 1.1 全都在里面，不用在那台机器上重配。
4. 那台机器如果也要用这个网页：把整个 `b101-light` 文件夹拷过去（不用装 node，里面带了运行环境），双击 `启动控制台.bat`。

> 注意：`SaveShow "新名字"` 在控台上等于「另存为并切换当前 show」，所以之后再存不带名字也是存到这个名字。想回到原来的 tutorial1，就 Backup → Load Show 选它。
> 每次保存只保留控台侧一个文件（同名覆盖），本机 `exports` 里的历史版本不会丢。

## 四、出问题

| 现象 | 处理 |
| --- | --- |
| 右上角「控台未连接」 | onPC 没开，或 Telnet 没开（见上文 `Assign "Global" /Telnet="Login Enabled"`） |
| 点灯没反应，日志里是 `Error ...` | 看日志里的英文报错；多半是灯具号不存在 |
| 改了配接，界面还是旧的 | 点 **同步** |
| 控台上的 cue 跟网页对不上 | 点 cue 区的 **同步**（把 `cues.json` 整条重写进控台） |
| 改了 cue 但控台没变 | 每次改都会自动重写，约 1–2 秒；没变就看右下角日志里的 `Import` 结果 |
| 页面白屏 | 页面上会出现红色报错框，把内容发我 |
| 端口 8801 被占 | 改 `server.js` 里 `process.env.PORT` 或删掉占用进程 |

## 六、它到底发了什么命令

| 操作 | 发出的命令 |
| --- | --- |
| 亮度 | `Fixture 21 Thru 33 At 60 Fade 2` |
| 彩光颜色 | `Fixture 21 Thru 33` ↵ `Attribute "COLORRGB1" At 100` ↵ `COLORRGB2` ↵ `COLORRGB3` |
| 色温灯 | `Fixture 7 Thru 14` ↵ `Attribute "COLORRGB6" At 92` ↵ `COLORRGB7 At 8` |
| 效果 | 每帧按亮度分档 `Fixture … At <值>` |
| 记一条 cue | `Store Cue 1 Executor 1.1`（建 sequence）→ 整条 XML `Import "b101cues" At Cue 1 Executor 1.1 /nc` |
| GO | `Clear` `Clear` `Goto Cue 1 Executor 1.1`，之后每条 `Go Executor 1.1` |
| 存演出 | `SaveShow "b101_live" /noconfirm`，然后等文件写稳再复制到 `exports\` |
| 停 | `Clear` `Clear` `Off Executor 1.1` |
| 暂停 / 继续 | `Pause On Executor 1.1` / `Pause Off Executor 1.1` |
| 读控台的 cue | `List Executor`（找哪条 executor 挂了 sequence）→ `Export Cue 1 Thru 999 Executor 1.1 "b101read"` → 读 `importexport\b101read.xml` |
| 黑场 | `Blackout On` / `Blackout Off` |
| Clear | `Clear` ×3 |

两个踩过的坑，已经绕开：
- 控台**不认 `\n` 换行**，必须 `\r\n`；
- `Group 5 Attribute "COLORRGB2" At 60` 这种「选灯和属性写在同一行」会被静默忽略，必须先选灯再发属性。

## 七、左边的舞台平面会跟着演出走

点「完整预览」或按 GO 之后，左上角那块平面图会**实时变色**：亮度跟着 fade 渐变、彩光跟着 RGB 走、色温灯跟着暖冷走。
标题旁边会出现一个闪动的「实时预览」小标签。

- 这只是本地跟着 cue 算出来的画面，用来对灯光本，不额外发命令给控台；
- 点「停止」后平面回到你手上这组灯的显示；
- 帧率 12 帧/秒，够看渐变过程，也不占控台带宽。

## 八、完整预览 / 暂停 / 停止

| 按钮 | 干什么 | 发出去的 |
| --- | --- | --- |
| **完整预览** | 从第 1 条开始，把整条 cue 列表放一遍（顺序、触发方式、时长都按列表） | 同步整条 XML → `Goto Cue 1 Executor 1.1` |
| **暂停** | 停在这一帧（按钮变「继续」）；再点一次从原地接着走 | `Pause On Executor 1.1` / `Pause Off Executor 1.1` |
| **停止** | 停掉这条 sequence，灯回黑场 | `Clear` `Clear` `Off Executor 1.1` |

暂停用的是控台自己的 `Pause` 键，所以：

- 控台上正在跑的 crossfade、时间码、效果都会一起停住；
- MA3D 是跟着控台输出画画的，没有自己的播放器 —— 控台停住，3D 也停在同一帧，继续时一起走；
- 暂停不会改变 cue 的位置，继续是「从原地接上」，不是重头再来。

> 小提示：第一次点「完整预览」会先把整条列表写进控台（约 2–3 秒），之后再点就很快。
